# Student Login System 🎓

### A Simple Student Portal with Digital Notes

A responsive web application built using **HTML, CSS, and JavaScript** that allows students to register, log in, and manage personal study notes through a simple, purple-themed dashboard.

---

## Features

- 🔐 **Student Registration & Login** – Register and log in using student credentials.
- 👁️ **Password Visibility** – Show or hide passwords using eye icons.
- ✅ **Form Validation** – Validate email formats and password requirements.
- 📚 **Digital Notes** – Create, save, view, and delete personal notes.
- 💾 **Data Persistence** – Store student details and notes using browser Local Storage.
- 🔄 **Session Management** – Restore the current session after refreshing the page.
- 📱 **Responsive Design** – Support desktop and mobile screens.
- 🎨 **Modern UI** – Clean layout with a consistent purple theme.

---

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Web page structure |
| CSS3 | Styling and responsive layout |
| JavaScript | Application logic and form validation |
| Local Storage | Store student details and notes |
| Session Storage | Maintain the current login session |

## Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (optional)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Rekha2805/Student_loginsystem.git
```

**2. Navigate to the project directory**

```bash
cd Student_loginsystem
```

**3. Run the application**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

---

## How to Use

1. Register with your name, email, and password.
2. Log in using your registered credentials.
3. Access your student dashboard.
4. Create study notes by entering a title and content.
5. Save and manage your notes.
6. Log out when finished.

## Security Note

This project is intended for educational purposes. Passwords are currently stored as plain text in browser Local Storage, and authentication is handled on the client side. It should not be used with real credentials. A production version would require secure backend authentication and password hashing.
